# 轮盘撬锁 自动辅助（B 方案 / 全自动）

截屏 → 视觉识别（指针 + 扇形高亮条）→ 指针落入扇形即自动点左键撬锁；离目标远时按住右键加速逼近，临近时松开保命中。

**只判"是否命中"，不分黄/蓝、不排优先级**（打中任意扇形都算一次撬锁）。识别**不依赖固定颜色阈值**（扇形会随时间变暗/变细）：在 Lab 空间用「相对底环的显著偏离」把环带里所有显著径向段切出来，再**按角宽分**——**细段(很窄) = 指针，宽段(填充弧) = 扇形**；指针落在某扇形角度内即命中。指针并入扇形时没有独立细段，按"已在扇形内"处理。所以**标定只需点圆环几何，不用取色**。

> ⚠️ 该小游戏带排行榜，自动点击属第三方辅助，**可能违反游戏 ToS、有封号风险**。仅建议个人离线练手/学习用，勿用于冲公开榜。

## 安装

```powershell
pip install -r requirements.txt
```

## 使用

1. **游戏用「窗口化 / 无边框窗口」模式**（独占全屏可能截到黑屏）。若点击/热键不生效，**用管理员身份**运行 PowerShell 再跑脚本（游戏以管理员运行时必须）。

2. **标定**（只标圆环几何，生成 `config.json`，换分辨率/窗口位置后要重标）：
   ```powershell
   python auto_unlock.py --calibrate
   ```
   - 沿**外环**边缘点 4~6 个点（窗口接近全屏、实时画出拟合圆，贴住环线最准）→ 按 **`n`**
   - 沿**内环**边缘点 4~6 个点 → 按 **`n`** → 按 **`Enter`** 保存

   圆心由多点拟合自动算出（**不用手点圆心**，多点可抹平点击误差）。键位：`n` 下一步 / `r` 重抓 / `Enter` 保存 / `Esc` 取消。保存时打印半径 `±` 抖动，越小越准。

3. **先开 debug 看识别准不准**：
   ```powershell
   python auto_unlock.py --debug
   ```
   黄弧=识别到的扇形（按实际弧长画出），**指针正落在其中时该弧变红=判为命中**；蓝线=指针。控制台还会打诊断：
   - `runW=[...]`：环带里各显著段的角宽（看 `pointer_max_arc` 该设多少——那个恒定的细段是指针）；
   - `trkMaxSal`/`salPx`：显著度统计（看 `arc_salience` 该多少）；`ptr`/`nSec`：识别到的指针角/扇形数。

4. **正式运行**：
   ```powershell
   python auto_unlock.py
   ```
   把鼠标放进游戏窗口 → **F8** 开始/暂停（会打印 `▶ 运行中`，没打印多半是热键没收到→用管理员跑），**F9** 退出。控制台打 `fps=`，**指针越快（右键加速）越需要高 fps**；若 fps 偏低且高速漏点，调小/关掉 `boost`。

## 调参（`config.json`）

| 参数 | 作用 | 调整方向 |
|---|---|---|
| `latency` | 点击延迟提前量(秒) | **最关键**。总是点早→调小(可到 0)；总是点晚→调大 |
| `arc_salience` | 显著阈值(相对底环偏离) | 扇形/指针(尤其变暗后)测不到→调小；底环/反光被误检→调大。对照 `trkMaxSal` 设 |
| `pointer_max_arc` | 指针/扇形分界(度) | **细=指针、宽=扇形**的单一边界(无死区)：≤此值=指针，>此值=扇形。实测指针**恒定 4~5°**(同一根等角宽针)、扇形约 17°且随时间变窄；默认 6 留 +1° 余量。指针没被识别→调大；窄扇形被当指针→调小。对照 `runW` 设 |
| `bar_max_arc` | 扇形角宽上限(度) | 扇形基本 ≤~30°，更宽的判为反光/误检丢弃。大块误检→调小 |
| `bar_min_px` | 某角度算"有东西"的最少像素 | 噪点多→调大；目标偏小测不到→调小 |
| `min_click_interval` | 两次点击最小间隔(秒) | 误连点→调大；漏点→调小 |
| `boost.enabled` / `boost.release_deg` | 自适应加速(按住右键) | 想稳/帧率低→设 `false`；高速冲过头→`release_deg`调大 |
| `click_pos` | 左键点击坐标 `[x,y]` | 默认 `null`=原地点击(不移光标，自己把光标停在不影响区)；要固定点位再填坐标 |

## 机制要点

- **不靠颜色，靠"宽度分段"**：环带内显著段，**细的是指针、宽的是扇形**；指针落入扇形即命中。检测用「相对底环偏离」而非固定颜色阈值，整体变暗时基准随之移动，故抗褪色。
- **指针并入扇形 = 命中**：指针很细，压到扇形上时与扇形连成一段、切不出独立细段；此时"没有指针细段 + 有扇形"即判命中。指针在缝隙时会切出独立细段，不在任何扇形内 → 不点。
- **命中即点**：打中扇形任意位置都算一次撬锁，不必分黄/蓝、不必瞄中心。
- **右键加速**让指针更快、要求更高帧率；用 `guard=半帧角位移` 防止两帧间跨过窄扇形漏判；运行看 `fps=`，不够就降 `boost`。

## 已知限制 / 未验证

- **未在真实游戏上测过**：`arc_salience`/`pointer_max_arc`/`latency` 都需按实机用 `--debug` 标定微调。
- **调试顺序**：先用 `--debug` 看控制台 `runW`/`trkMaxSal` 等真实数值 → 据此设 `arc_salience`（让扇形/指针被切出来）和 `pointer_max_arc`（把细的判成指针、宽的判成扇形，对照 `runW` 里那个恒定的细段宽度设其上一点）→ 最后调 `latency` 修早/晚。
- 宽度区分的边界：扇形若缩到比 `pointer_max_arc` 还窄会被误判为指针；指针若很粗会被误判为扇形。靠 `--debug` 的 `runW` 设好两者的分界。
- 多显示器：标定默认抓主显示器；游戏放副屏需相应调整。
