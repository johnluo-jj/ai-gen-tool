# 轮盘撬锁 自动辅助（B 方案 / 全自动）

截屏 → 视觉识别（指针 + 扇形高亮条）→ 指针落入扇形即自动点左键撬锁；离目标远时按住右键加速逼近，临近时松开保命中。

**只判"是否命中"，不分黄/蓝、不排优先级**（打中任意扇形都算一次撬锁）。识别在 Lab 空间用「相对底环的显著偏离」对每个角度取最大值成廓：**指针 = 最亮的发光团**（真机指针带强发光、不是细线，是廓里的峰）；**扇形 = 排除指针发光窗后、宽度合规、最强的至多 2 条弧**。指针(含延迟提前量)落入某扇形角度内即点。所以**标定只需点圆环几何，不用取色**。

> ⚠️ 该小游戏带排行榜，自动点击属第三方辅助，**可能违反游戏 ToS、有封号风险**。仅建议个人离线练手/学习用，勿用于冲公开榜。

## 安装

```powershell
pip install -r requirements.txt
```

## 使用

1. **游戏用「窗口化 / 无边框窗口」模式**（独占全屏可能截到黑屏）。若点击/热键不生效，**用管理员身份**运行 PowerShell 再跑脚本（游戏以管理员运行时必须）。

2. **标定**（只标圆环几何，生成 `config.json`，换分辨率/窗口位置后要重标）：
   ```powershell
   python auto_unlock.py --calibrate
   ```
   - ⚠ 要标的是**黄蓝条所在的那一圈环带**，不是表盘最外的装饰大环。
   - 沿**黄蓝条外侧**边缘点 4~6 个点（窗口接近全屏、实时画出拟合圆最准）→ 按 **`n`**
   - 沿**黄蓝条内侧**边缘点 4~6 个点 → 按 **`n`** → 按 **`Enter`** 保存

   圆心由多点拟合自动算出（**不用手点圆心**，多点可抹平点击误差）。键位：`n` 下一步 / `r` 重抓 / `Enter` 保存 / `Esc` 取消。保存时打印半径 `±` 抖动，越小越准。

3. **诊断识别**（识别为空 `nSec=0/ptr=-` 时先跑这个定位问题，强烈建议第一次先做）：
   ```powershell
   python auto_unlock.py --snapshot
   ```
   倒计时 5 秒内把游戏切前台、露出表盘 → 抓一帧并存盘：
   - `_snap_roi.png`：原始抓取（看有没有截到表盘 / 是不是黑屏）；
   - `_snap_band.png`：绿圈=标定的环带，**看是否正压在黄蓝条上**（错位则后面阈值怎么调都没用）；
   - `_snap_sal.png`：显著度热图（亮=被判为"有东西"）。

   控制台还打印 `环带像素数`、`环带显著度 max/p99/中位`、以及**各 `arc_salience` 阈值下能切出的段宽**——据此设 `arc_salience` 并确认几何。

4. **看识别准不准（可视化）**：
   ```powershell
   python auto_unlock.py --debug
   ```
   - 黄弧 = 采纳的扇形(至多2条)；蓝线 = 指针(最亮发光团的峰角)。
   - **bot 决定点击的那一刻：扇形变绿 + 屏幕大字 `CLICK`**。⚠ 这是 **bot 自己的点击决策**，跟游戏里「点错 → 指针变红」是两码事，别混淆——所以这里特意用**绿**不用红。
   - 画面底部叠 `runW`(显著段角宽) / `secW`(采纳扇形角宽) / `maxSal`，方便直接截图。
   - 控制台打 `ptrSeen=%`(指针识别率) 和 `hit=Y/n  clicks=N`，确认指针有没有认到、左键有没有真点出去。

5. **正式运行**：
   ```powershell
   python auto_unlock.py
   ```
   把鼠标放进游戏窗口、停在不挡表盘处 → **F8** 开始/暂停（会打印 `▶ 运行中`，没打印多半是热键没收到→用管理员跑），**F9** 退出。控制台打 `fps=`，**指针越快（右键加速）越需要高 fps**；若 fps 偏低且高速漏点，调小/关掉 `boost`。

## 调参（`config.json`）

| 参数 | 作用 | 调整方向 |
|---|---|---|
| `latency` | 点击延迟提前量(秒) | **最关键**。总是点早→调小(可到 0)；总是点晚→调大 |
| `arc_salience` | 显著阈值(每角度最大"亮+彩"偏离) | 扇形/指针(尤其变暗后)测不到→调小；反光/边缘环被误检→调大。对照 `--debug` 的 `maxSal` 设 |
| `pointer_glow_arc` | 指针发光团半角宽(度) | 排除指针±此角，免得把发光当扇形。发光团残留被当扇形→调大；近指针的真扇形被吃掉→调小 |
| `bar_min_arc` / `bar_max_arc` | 扇形角宽下/上限(度) | 细于下限=噪点丢弃；宽于上限=整圈反光/边缘环丢弃。对照 `runW`/`secW` 设 |
| `max_sectors` | 最多保留几个扇形 | 游戏最多 2 个；只取最强的前几条，防止满屏假扇形导致乱点 |
| `min_click_interval` | 两次点击最小间隔(秒) | 误连点→调大；漏点→调小 |
| `boost.enabled` / `boost.release_deg` | 自适应加速(按住右键) | 想稳/帧率低→设 `false`；高速冲过头→`release_deg`调大 |
| `click_pos` | 左键点击坐标 `[x,y]` | 默认 `null`=原地点击(不移光标，自己把光标停在不影响区)；要固定点位再填坐标 |

## 机制要点

- **指针 = 最亮发光团，扇形 = 排除指针后最强的至多 2 条弧**：真机指针带强发光、不是细线，所以取「每角度最大显著度」成廓后的峰为指针，并把其发光窗挖掉再找扇形；整圈反光/内边缘环会铺满成一条 360° 段被宽度上限丢弃，不再碎成几十个假扇形。检测用相对底环偏离、非固定颜色阈值，整体变暗时基准随之移动，故抗褪色。
- **只在"看到指针且指针落入扇形"时才点**：识别不到指针(`pointer=None`)时**不点**——因为分不清是"并入扇形(命中)"还是"漏检"，盲点会一直误点(游戏里点错有惩罚)。待 `--debug` 用 `ptrSeen%` 确认指针在缝隙里能稳定识别后，再议是否恢复"并入即命中"。
- **命中即点**：打中扇形任意位置都算一次撬锁，不必分黄/蓝、不必瞄中心。
- **右键加速**让指针更快、要求更高帧率；用 `guard=半帧角位移` 防止两帧间跨过窄扇形漏判；运行看 `fps=`，不够就降 `boost`。

## 已知限制 / 未验证

- **真机仍在调试中**：实测可能出现 detect 识别为空（`nSec=0/ptr=-`，则零点击）。此时**先 `--snapshot`** 看环带是否压在条上、`arc_salience` 该多低，再继续。
- **调试顺序**：① `--snapshot` 定环带几何 + `arc_salience`（对照 `maxSal` 和各阈值段宽，让指针/扇形被切出来、反光被滤掉）→ ② `--debug` 看 `nSec`/`secW` 是否≤2 且对得上真实扇形、`ptrSeen%` 是否够高 → ③ 调 `latency` 修早/晚。
- **未验证的关键假设**：detect 认为「指针(发光团)是环带里最亮的」。真机若出现比指针更亮的扇形，可能把扇形误当指针——需用有黄蓝条出现时的 `--snapshot`/`--debug` 核实，必要时改用颜色/运动区分。
- 多显示器：标定默认抓主显示器；游戏放副屏需相应调整。
