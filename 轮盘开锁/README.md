# 轮盘撬锁 自动辅助（B 方案 / 全自动）

截屏 → 视觉识别（指针 + 扇形高亮条）→ 指针落入扇形即自动点左键撬锁；离目标远时按住右键加速逼近，临近时松开保命中。

**只判"是否命中"，不分黄/蓝、不排优先级**（打中任意扇形都算一次撬锁）。识别**不依赖固定颜色阈值**（扇形会随时间变暗/变细）：在 Lab 空间用「相对底环的显著偏离」找扇形（整体变暗时基准随之移动，故抗褪色）；指针按「外圈尖端发白（高亮 + 低彩）」定位。所以**标定只需点圆环几何，不用取色**。

> ⚠️ 该小游戏带排行榜，自动点击属第三方辅助，**可能违反游戏 ToS、有封号风险**。仅建议个人离线练手/学习用，勿用于冲公开榜。

## 安装

```powershell
pip install -r requirements.txt
```

## 使用

1. **游戏用「窗口化 / 无边框窗口」模式**（独占全屏可能截到黑屏）。若点击/热键不生效，**用管理员身份**运行 PowerShell 再跑脚本（游戏以管理员运行时必须）。

2. **标定**（只标圆环几何，生成 `config.json`，换分辨率/窗口位置后要重标）：
   ```powershell
   python auto_unlock.py --calibrate
   ```
   - 沿**外环**边缘点 4~6 个点（窗口接近全屏、实时画出拟合圆，贴住环线最准）→ 按 **`n`**
   - 沿**内环**边缘点 4~6 个点 → 按 **`n`** → 按 **`Enter`** 保存

   圆心由多点拟合自动算出（**不用手点圆心**，多点可抹平点击误差）。键位：`n` 下一步 / `r` 重抓 / `Enter` 保存 / `Esc` 取消。保存时打印半径 `±` 抖动，越小越准。

3. **先开 debug 看识别准不准**：
   ```powershell
   python auto_unlock.py --debug
   ```
   黄弧=识别到的扇形（按实际弧长画出），**指针正落在其中时该弧变红=判为命中**；蓝线=指针。看扇形范围对不对、指针贴不贴、命中时机对不对，飘就调参（见下）。

4. **正式运行**：
   ```powershell
   python auto_unlock.py
   ```
   把鼠标放进游戏窗口 → **F8** 开始/暂停，**F9** 退出。控制台会打 `fps=`，**指针越快（右键加速）越需要高 fps**；若 fps 偏低且高速漏点，调小/关掉 `boost`。

## 调参（`config.json`）

| 参数 | 作用 | 调整方向 |
|---|---|---|
| `latency` | 点击延迟提前量(秒) | **最关键**。总是点早→调小(可到 0)；总是点晚→调大 |
| `arc_salience` | 扇形检测阈值(相对底环偏离) | 扇形(尤其变暗后)测不到→调小；底环/反光被当成扇形→调大 |
| `white_l_min` / `white_chroma_max` | 指针尖端"发白"判定(亮度下限/彩度上限) | 指针测不到→`white_l_min`调小、`white_chroma_max`调大；杂物被当指针→反向 |
| `tip_band` | 指针尖端检测带占环宽比例 | 指针尖端没覆盖到→调大 |
| `pointer_guard_deg` | 找扇形时排除指针±该角度 | 指针被当成扇形→调大；扇形贴着指针测不到→调小 |
| `bar_min_arc` | 扇形最小角宽(度) | 变细的扇形被滤掉→调小；噪点被当成扇形→调大 |
| `bar_min_px` / `pointer_min_px` | 认定所需最少像素 | 噪点多→调大；目标偏小测不到→调小 |
| `min_click_interval` | 两次点击最小间隔(秒) | 误连点→调大；漏点→调小 |
| `boost.enabled` / `boost.release_deg` | 自适应加速(按住右键) | 想稳/帧率低→设 `false`；高速冲过头→`release_deg`调大 |
| `click_pos` | 左键点击坐标 `[x,y]` | 默认 `null`=原地点击(不移光标，自己把光标停在不影响区)；要固定点位再填坐标 |

## 机制要点

- **命中即点**：指针(含延迟提前量)落入任一扇形角度区间就点；打中扇形任意位置都算一次撬锁，所以不必分黄/蓝、不必瞄中心。
- **扇形会"变细 + 变暗"**：检测用「相对底环偏离」而非固定颜色阈值，整体变暗时基准随之移动，故抗褪色；最小角宽 `bar_min_arc` 放小以跟住变细的扇形。
- **指针与扇形同处环轨、且指针是「蓝紫→近白」渐变**：靠**尖端发白(高亮+低彩)**定位，与彩色扇形天然分开，再把指针角度从扇形检测里排除。
- **右键加速**会让指针更快，对截图帧率要求更高；运行时看 `fps=`，并用 `guard=半帧角位移` 防止两帧间跨过窄扇形漏判；帧率仍不够就降 `boost`。

## 已知限制 / 未验证

- **未在真实游戏上测过**：`arc_salience`/`white_*`/`latency` 等都需按实机用 `--debug` 标定微调。
- 调试顺序建议：先看 `--debug` 里**扇形范围对不对**（调 `arc_salience`/`bar_min_arc`）→ 再看**指针是否贴住**（调 `white_*`/`tip_band`）→ 最后调 `latency` 修早/晚。
- 多显示器：标定默认抓主显示器；游戏放副屏需相应调整。
