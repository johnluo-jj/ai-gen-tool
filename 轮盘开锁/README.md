# 轮盘撬锁 自动辅助（B 方案 / 全自动）

截屏 → 视觉识别（蓝指针 / 黄高亮条 / 蓝加时条）→ 自动点左键撬锁；离目标远时按住右键加速逼近，临近时松开保命中。

> ⚠️ 该小游戏带排行榜，自动点击属第三方辅助，**可能违反游戏 ToS、有封号风险**。仅建议个人离线练手/学习用，勿用于冲公开榜。

## 安装

```powershell
pip install -r requirements.txt
```

## 使用

1. **游戏用「窗口化 / 无边框窗口」模式**（独占全屏可能截到黑屏）。若点击不生效，**用管理员身份**运行 PowerShell 再跑脚本（游戏以管理员运行时必须）。

2. **标定**（生成 `config.json`，换分辨率/窗口位置后要重标）：
   ```powershell
   python auto_unlock.py --calibrate
   ```
   流程（圆心由多点拟合自动算出，**不用手点圆心**）：
   1. 沿**外环**边缘点 4~6 个点（会实时画出拟合圆，贴住环线最准）→ 按 **`n`** 下一步
   2. 沿**内环**边缘点 4~6 个点 → 按 **`n`**
   3. **取色**（点哪只为采颜色；每步可点多处，按 `n` 进入下一步，没有可按 `s` 跳过）：
      - **蓝指针**：沿指针点**几个点**——指针是「内端蓝紫 → 外端近白」的渐变发光，多点几处(尤其内端蓝紫段)才能覆盖整条，白色尖端可不点；
      - **蓝加时条** / **黄高亮条**：各点 1~3 处。
   4. 按 **`Enter`** 保存

   键位：`n` 下一步 / `s` 跳过取色 / `r` 重抓画面 / `Enter` 保存 / `Esc` 取消。保存时会打印半径的 `±` 抖动，越小越准。

3. **先开 debug 看识别准不准**：
   ```powershell
   python auto_unlock.py --debug
   ```
   蓝线=识别到的指针，黄点/蓝点=识别到的弧条中心。识别飘就回去调参（见下）。

4. **正式运行**：
   ```powershell
   python auto_unlock.py
   ```
   把鼠标放进游戏窗口 → **F8** 开始/暂停，**F9** 退出。

## 调参（`config.json`）

| 参数 | 作用 | 调整方向 |
|---|---|---|
| `latency` | 点击延迟提前量(秒) | **最关键**。总是点早→调小(可到 0)；总是点晚→调大 |
| `min_click_interval` | 两次点击最小间隔 | 误连点→调大；漏点→调小 |
| `fire_base_tol` | 瞄准弧条中心的基础容差(度) | 高速时漏点→调大；空点受惩罚→调小 |
| `pointer_guard_deg` | 找蓝加时条时排除指针±该角度 | 蓝针被当成加时条→调大；加时条贴着指针测不到→调小 |
| `bar_min_arc` | 弧条最小角宽(度) | 变细的条被滤掉→调小；噪点被当成条→调大 |
| `pointer_band`/`bar_band` | 指针带/弧条带占环宽比例 | 指针测不到→`pointer_band`调大；弧条测不到→`bar_band`调大 |
| `bar_min_px`/`pointer_min_px` | 认定所需最少像素 | 噪点多→调大；目标偏小测不到→调小 |
| `boost.enabled` | 是否自适应加速(按住右键) | 想稳一点可设 `false`(先关掉调好精度再开) |
| `boost.release_deg` | 离目标多少度内松开右键 | 高速冲过头→调大 |
| `click_pos` | 左键点击坐标 `[x,y]` | 默认 `null`=原地点击(不移动光标，自己把光标停在不影响区)；如需固定点击位置再填坐标 |

## 机制要点

- **弧条(黄/蓝)的弧长会随时间逐渐变细**。所以点击**瞄准弧条中心**而非整条范围：边缘会缩、中心不动，这样既不会提前点空、也抗变细。
- **蓝指针与蓝加时条都是蓝色**，靠「内圈测指针 / 外圈测弧条 + 排除指针角度附近 + 单独取色」区分。**强烈建议标定时单独点一下蓝加时条**(标定多了一步)，否则只能沿用蓝指针的蓝，颜色不一致就测不到加时条。

## 已知限制 / 未验证

- **未在真实游戏上测过**：颜色阈值、半径分层、`latency` 都需按实机用 `--debug` 标定微调。
- 若仍偏早/偏晚，先调 `latency`；蓝条测不到先确认标定单独取了蓝加时条、再把 `bar_min_arc` 调小。
- 多显示器：标定默认抓主显示器；游戏放副屏需相应调整。
